# FleetFlow

## Opis projektu
FleetFlow to aplikacja webowa do zarządzania trasami transportowymi w firmach.

## Problem
System ma ułatwiać dodawanie tras, przydzielanie ich pracownikom oraz kontrolowanie postępu realizacji zleceń.

## Role użytkowników
- Owner — właściciel firmy.
- Dispatcher — dyspozytor.
- Employee — pracownik.

## Funkcje pierwszej wersji (MVP)
- Wyświetlanie dostępnych tras.
- Dodawanie nowych tras.
- Przyjmowanie tras przez pracowników.
- Ręczne przypisywanie tras przez dyspozytora.
- Zmiana statusu trasy.
- Historia zleceń.

## Technologie
- HTML, CSS, JavaScript — początek projektu.
- Node.js i Express — backend.
- PostgreSQL — baza danych.
- React i TypeScript — planowany frontend.

## Status projektu
Planowanie i przygotowanie pierwszej wersji.
